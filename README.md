To use agda, here are the recommended options.

1. (quick installation with a slower run-time) using https://agda-web.github.io/
    1. you need to sign in to your github account
    2. clone this repo in the vscode.dev web UI
    3. install the 3 extensions mentioned in agda-web project.
    4. install the standard library as per instructed in the agda-web project 
2. (full local installation) using https://agda.readthedocs.io/en/stable/getting-started/installation.html
    1. don't use the pre-built agda binary
    2. install ghcup, ghc, cabal
    3. install agda using cabal
    4. install the standard library
    5. configure your editors, vscode is fine, emacs is the best.
3. (full local installation) using https://plfa.github.io/GettingStarted/
